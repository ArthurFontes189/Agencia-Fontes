# Checklist da demo (fase 1)

## Antes de montar
- [ ] Negócio escolhido e visitado por quem vai apresentar
- [ ] Dados reais conseguidos com o dono ou de fonte pública que ele reconhece
- [ ] Nicho e seções definidos

## Ao montar (`/novo-cliente`)
- [ ] Projeto criado em `clientes/<slug>` com git próprio, sem remoto
- [ ] Faixa "Modelo de demonstração" ativa e botão "Quero um site assim"
- [ ] Cores e fontes do cliente (não as da agência)
- [ ] Nada inventado: horário, preço, depoimento, número ou endereço desconhecido
      virou `[PREENCHER]` ou saiu da página
- [ ] `npm run build` passou

## Antes de mostrar
- [ ] Testado no celular que será usado na visita (`npm run dev -- --host`)
- [ ] Sem link ou página publicada com a marca do cliente
- [ ] Plano de preço e prazo decididos por quem vai apresentar

## Depois da visita
- [ ] Resultado anotado no `STATUS.md` (aceitou, pensar, recusou)
- [ ] Recusou: arquivar ou apagar a demo e os dados do negócio
