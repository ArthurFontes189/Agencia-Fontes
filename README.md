# Plataforma da Agência Digital

Plataforma profissional que funciona como vitrine de serviços, portfólio de trabalhos e porta de entrada para novos clientes.

## 📋 Visão Geral

Plataforma integrada que apresenta os serviços da agência:
- 🌐 **Websites** - Desenvolvimento web profissional
- 💼 **Sistemas de Gestão** - Software customizado para empresas
- 📢 **Marketing e Propaganda** - Estratégias digitais
- 🎬 **Edição de Vídeos e Fotos** - Conteúdo visual criativo

## 🏗️ Arquitetura

```
├── frontend/          # Aplicação React (Vitrine + Dashboard)
├── backend/           # API Node.js/Express
├── docs/              # Documentação do projeto
├── tests/             # Testes automatizados
└── .github/           # Configurações GitHub
```

## 🚀 Como Começar

### Pré-requisitos
- Node.js 18+
- npm ou yarn
- Git

### Instalação

1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/plataforma-agencia.git
cd plataforma-agencia
```

2. Instale as dependências do backend
```bash
cd backend
npm install
```

3. Instale as dependências do frontend
```bash
cd ../frontend
npm install
```

### Desenvolvimento

**Backend:**
```bash
cd backend
npm run dev
```

**Frontend:**
```bash
cd frontend
npm start
```

## 📝 Variáveis de Ambiente

Copie `.env.example` para `.env` e configure suas variáveis:

```bash
cp .env.example .env
```
